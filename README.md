# SLM Platform with Prometheus and Grafana with Terraform

## Description
This is a an example for how to setup a Service Level Monitoring platform for an organization based on Prometheus for scraping data from various systems and services and Grafana for visualization and Terraform to deploy Grafana resources. It serves as support for a relevant blog post at https://www.mythryll.com/ (link will be updated soon).
